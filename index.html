Seattle Demolition Permits

Nov 16th, 2022

An interactive presentation of Seattle's demolition permitting, this web map is one of two projects through which I became familiar with the MapboxGL API and the City of Seattle's OpenData portal. Though this project's assigned API token sits client-side, the skillful application of Mapbox's url whitelisting functionalities prevent any opportunity for abuse.

Good user experience was maintained by my identifying and removing an unexpected race condition, a feat not to be outshined by my grappling with the challenge to design a page that assumes no standard resolution nor screen size.
